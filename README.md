# Layer Lock Tool - MySystem

ابزار سبک ویندوز 11 برای ثابت نگه‌داشتن پنجره‌ها در لایهٔ بالاتر، با گزینه‌ای داخل همان منوی بومی نوار عنوان ویندوز.

## نصب

1. از بخش **Releases** آخرین فایل `LayerLockTool-win-x64.zip` را دانلود کنید. برای ویندوزهای ARM فایل `win-arm64` را بگیرید.
2. فایل ZIP را Extract کنید و `LayerLockTool.exe` را اجرا کنید.
3. آیکون برنامه در System Tray قرار می‌گیرد. از منوی آیکون می‌توان اجرای خودکار همراه ویندوز را فعال کرد.

برنامه به نصب .NET نیاز ندارد و به‌صورت self-contained ساخته می‌شود.

## استفاده

- روی قسمت خالی **نوار عنوان** مرورگر، تلگرام یا هر پنجرهٔ دیگر راست‌کلیک کنید.
- گزینهٔ **قفل لایه (همیشه بالا)** را بزنید. تیک کنار گزینه یعنی پنجره قفل است.
- برای بازکردن قفل، همان گزینه را دوباره بزنید.
- میان‌بر جایگزین: `Win + Ctrl + Space` روی پنجرهٔ فعال.
- از منوی System Tray می‌توان یک پنجره یا همهٔ پنجره‌ها را از قفل خارج کرد.

## رفتار چند پنجرهٔ قفل‌شده

- قفل بر اساس **خود پنجره** اعمال می‌شود، نه نام یا پردازش برنامه؛ بنابراین دو پنجرهٔ جداشده از یک مرورگر مستقل هستند و فقط همان پنجره‌ای که انتخاب شده قفل می‌شود.
- تمام پنجره‌های قفل‌شده همیشه بالاتر از پنجره‌های عادی می‌مانند.
- میان خود پنجره‌های قفل‌شده، **آخرین پنجرهٔ فعال‌شده بالاتر قرار می‌گیرد**؛ بقیه با ترتیب آخرین استفاده زیر آن می‌روند.
- کلیک روی یک برنامهٔ عادی، آن را بالاتر از پنجره‌های قفل‌شده نمی‌آورد.
- Minimize کردن مجاز است؛ بعد از Restore، پنجره همچنان در لایهٔ قفل‌شده می‌ماند.
- با بستن برنامه یا خروج از Layer Lock Tool، وضعیت پنجره‌ها به حالت قبل برمی‌گردد.

## ساخت پروژه

پیش‌نیاز: Visual Studio 2022 یا .NET 8 SDK روی ویندوز 11.

```powershell
dotnet restore
dotnet publish src/LayerLockTool/LayerLockTool.csproj -c Release -r win-x64 --self-contained true
```

خروجی در مسیر زیر ساخته می‌شود:

```text
src/LayerLockTool/bin/Release/net8.0-windows10.0.22000.0/win-x64/publish/
```

برای مدیریت پنجره‌هایی که با Administrator اجرا شده‌اند، خود ابزار را نیز با **Run as administrator** اجرا کنید.
